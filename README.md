# Формула Отдыха — демо-сайт

Статичный демо-сайт турагентства «Формула Отдыха» (Белгород). Vite + чистый JS, без бэкенда.
Сайт закрыт от поисковиков (`noindex`), в подвале стоит плашка «Демо-версия».

Сайт: https://masterchinhook.github.io/formula-otdyha-demo/

## Запуск

```bash
npm install
npm run dev        # локально, http://localhost:5173/formula-otdyha-demo/
npm run build      # сборка в dist/
npm run check      # после build: скриншоты 390px и 1440px в screenshots/, проверка консоли и формы
```

Каждый push в `main` сам публикует сайт на GitHub Pages (`.github/workflows/deploy.yml`).

## Как менять тексты

Все тексты лежат в **`src/content.js`**: название, адрес, телефоны, режим работы, заголовки, пункты «Почему к нам», шаги, подписи.
Правите строку, сохраняете, делаете push. Разметку трогать не нужно.

- Константа `TODO` на сайте выглядит как жёлтая плашка «[уточнить у агентства]». Когда данные появятся, замените `TODO` на текст.
- Режим работы: `agency.hours`. Если агентство работает по выходным, запишите строку, например `weekend: 'Сб 10:00–15:00, Вс — выходной'`.
- Плашка «Сейчас открыто / обед / закрыто» считается по московскому времени из `agency.hours.weekdays`.
- Мета-теги (title, description, og) лежат в `index.html`. Адрес сайта для og-тегов задаётся в `.env` (`VITE_SITE_URL`).

## Как менять направления

Массив `directions.items` в `src/content.js`: одна запись — одна карточка.

```js
{ title: 'Название', text: 'Пара слов о поездке', season: 'Май — октябрь', price: 'от 00 000 ₽' },
```

Карточек может быть сколько угодно. Кнопка «Спросить про это направление» сама подставляет название в форму заявки.

## Как добавить фото

Положите файлы `.jpg`, `.jpeg`, `.webp`, `.png` или `.avif` в **`public/photos/`**. Код подхватит их сам:

| Имя файла | Где появится |
|---|---|
| `hero.jpg` (или `.webp`) | главный экран; если такого файла нет, берётся первое фото по алфавиту |
| `about.jpg` | фото в блоке «Почему к нам обращаются» |
| остальные, по алфавиту (`01.jpg`, `02.jpg`…) | карточки направлений, по порядку |

Пока фото нет, на их месте стоят градиентные «пейзажи». Рекомендации: ширина 1600–2000px для hero и 1000px для карточек, лучше webp, до 300 КБ на файл.
Используйте только фото, на которые у агентства есть права.

## Адрес на GitHub Pages (base)

В `vite.config.js`: `base = process.env.BASE_PATH ?? '/formula-otdyha-demo/'`.
Если переименуете репозиторий, поменяйте путь там и в `.env`. Для своего домена соберите с `BASE_PATH=/`.

## Форма заявки

Бэкенда нет. Форма проверяет имя и телефон, собирает текст заявки, копирует его в буфер обмена и показывает кнопки «Позвонить» на оба номера.
В настоящем сайте сюда подключается отправка заявки (Telegram-бот, почта, CRM).
